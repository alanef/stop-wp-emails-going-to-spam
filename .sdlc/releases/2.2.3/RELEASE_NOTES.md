# Release 2.2.3

**Date:** 2026-10-23
**Previous:** v2.2.2

## Highlights

Fixes the opt-in settings notice that couldn't be dismissed and kept coming back, by updating the bundled opt-in
library to 1.3.3. Deleting the plugin now also removes the library's stored opt-in choice.

## What's New

### Fixes
- The settings notice could not be dismissed and came back on every page load.
- On sites running other Fullworks free plugins, the opt-in notice and menu could belong to the wrong plugin.
- Leaving the opt-in screen without choosing left the notice up for good. Visiting settings now shows the opt-in screen again until you click Allow or Skip.
- Deleting the plugin left the opt-in library's stored choice (`SWEGTS_form_rendered`) behind.

### Improvements
- The notice links straight to the opt-in screen.
- Bundled opt-in library updated to 1.3.3.
- FAQ entry on reporting security bugs through the Patchstack Vulnerability Disclosure Program (2b6967a).

## Breaking Changes

None.

## Migration Guide

None. Stored choices (`SWEGTS_form_rendered`) and dismissals (`SWEGTS_notice_dismissed`) are kept.
